# S22 cellular runtime closure — 2026-09-21

This is a bounded, host-only artifact recovery and static dependency audit. It
does not claim that cellular service works. No recovered AArch64 executable was
run, no Android service or modem interface was started, and no phone or radio
partition was touched.

## Source and destination

The source was the existing read-only F2FS copy
`rootfs/vendor-pristine-20260920.img` (SHA-256
`6dfe677119792e95a37b016092c327ad62bc0dc7759851424ad05e6bcb31b206`) using
the retained `/tmp/vendor-tree.txt` and `/tmp/blockmap.txt` metadata. Recovery
used `tools/hardware/recover-f2fs-file.py` for executables/RC files and
`tools/gpu-compat/recover-vendor-closure.py` for vendor `lib64` files.

The ignored result is `rootfs/cellular-reuse-20260921/`. Every file hash,
ELF header, and static `DT_NEEDED` result is in its
`manifest.json`, generated by `tools/hardware/manifest-cellular-closure.py`.
The manifest compares dependencies only with the isolated recovery runtime
at `rootfs/gpu-compat-20260921/runtime/system/lib64`; host glibc files are not
treated as Android dependencies.

## Static closure result

The isolated tree contains 41 files: 39 ELF files (the three entry points and
36 radio/RIL libraries) plus the two RC fragments. The manifest found:

- 33 distinct `DT_NEEDED` names recovered in the vendor closure;
- 12 names available in the isolated staged Bionic/system runtime;
- 6 names still missing: `android.hidl.safe_union@1.0.so`, `libexpat.so`,
  `libhardware_legacy.so`, `libnetutils.so`, `libsqlite.so`, and `libxml2.so`.

The recovered library set includes `libsec-ril.so`, `libsec_semRil.so`,
`libsecril-client.so`, `libshmemcompat.so`, `libshmemutil.so`, `libril_sem.so`,
`librilutils.so`, Android radio/config HIDL versions 1.0–1.6, Samsung radio
2.0–2.2, Samsung radio bridge 2.0–2.1, the Samsung radio channel interface,
and their vendor-side property/feature/HIDL support libraries. Exact sizes and
hashes for this full set are recorded in `manifest.json`.

This is a static closure, not a loader or ABI proof. In particular, the six
missing libraries and the referenced CP boot/diagnostic services must be
resolved from a matching Android system/vendor source before any isolated
runtime experiment is considered. No fallback implementation is supplied.

## Reusable audit command

From the repository root (host-only):

```sh
python3 tools/hardware/manifest-cellular-closure.py \
  rootfs/cellular-reuse-20260921 \
  rootfs/cellular-reuse-20260921/manifest.json \
  --system-root rootfs/gpu-compat-20260921/runtime/system/lib64 \
  --source-image-sha256 6dfe677119792e95a37b016092c327ad62bc0dc7759851424ad05e6bcb31b206 \
  --source-tree /tmp/vendor-tree.txt
```

The tool calls `readelf -h` and `readelf -d` only and records
`execution_performed: false` in the JSON output.
