# Obtaining Samsung firmware

This repository does not distribute Samsung firmware or device-specific binary blobs. Obtain firmware only for a device you own, using a source and process appropriate to your region and model. For stock firmware, use Samsung Smart Switch or download the matching package from a reputable source; verify the model/build and checksums before use. Extract it locally and do not commit firmware images, modem/radio blobs, boot/recovery binaries, or other proprietary payloads. This project cannot provide or redistribute firmware.
